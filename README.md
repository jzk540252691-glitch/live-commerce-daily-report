# 直播电商经营日报
同一场直播，补齐投流消耗后，更新同一份日报。以下为虚构直播间「云杉」的两次结果。

| 1 月 3 日 | 成交额 | 投流消耗 | ROI | 核对结果 |
|---|---:|---:|---:|---|
| 首次出报 | 5,400 元 | — | / | 待补：投流消耗 |
| 补数后 | 5,400 元 | 1,200 元 | 4.50 | 已齐 |

## 本地运行
使用 Python 3.8 或更高版本，在本目录执行：

```sh
python3 report.py example.csv 2026-01-03
python3 report.py corrected.csv 2026-01-03
python3 -m unittest
```

第一次运行后，用浏览器打开「日报-2026-01-03.html」。第二次运行后刷新页面。两份 CSV 均为模拟数据，覆盖两个直播间、连续三天。

## 指标口径
ROI 使用全场成交额除以投流消耗。已开播的空金额标为待补，实际填零的消耗保留为 0.00，两种情况下 ROI 均显示 /。未开播由填报人明确标注。这个公开示例在本地生成 HTML，无需账号或第三方依赖。
